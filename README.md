# Rajarajan TP – Portfolio

A minimal, futuristic portfolio built with **Vite + React + Tailwind**.

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Replace the resume

Put your PDF at:
```
public/Rajarajan_TP_Resume.pdf
```
and the site will automatically embed and offer it for download.

## Deploy

- **Vercel**: Import this repo and deploy.
- **Netlify**: Drag-and-drop the `dist` folder after `npm run build`.
- **GitHub Pages**: `npm run build` then publish `dist`.
